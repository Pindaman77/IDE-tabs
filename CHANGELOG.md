# Changelog

## v0.1.0-alpha.1 — 2026-10-20

First early alpha for Windows 11.

- Cursor and VS Code windows each gather into one workspace with a project sidebar.
- One taskbar button and Alt+Tab entry per workspace.
- Ctrl+Alt+H hides or shows the sidebar; the chevron collapses it to project initials.
- Minimal settings from the tray icon. No account, no telemetry, no network access.

Built on [WindowTabs](https://github.com/leafOfTree/WindowTabs).
